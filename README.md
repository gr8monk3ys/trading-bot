# trading-bot

Over 2020–2024 the best validated strategy returned +16.4% (Sharpe 0.16) vs SPY +95.3% (0.75). It does not beat buy-and-hold.

An Alpaca paper-trading bot in async Python, built to answer one question: can a retail RSI/MACD/ADX momentum system be tuned to beat the market? The answer is no, and most of the engineering here went into making sure the answer was measured rather than assumed.

**Do not deploy real capital.** Paper only.

## The result

| 2020–2024, SPY/QQQ/IWM/EFA universe | Total return | Sharpe | Trades |
|---|---|---|---|
| Momentum strategy, gross-100 target | **+16.4%** | 0.16 | 26 (below the 50-trade significance bar) |
| SPY buy-and-hold | **+95.3%** | 0.75 | — |

Source: [`results/etf_baseline_2020-2024_exposure_sweep.md`](results/etf_baseline_2020-2024_exposure_sweep.md), regenerated by `scripts/run_etf_baseline.py`. The strategy's own exit timing subtracts value at every exposure level (25/50/100% targets all trail SPY). The Bollinger-filter A/B ([`results/bollinger_filter_ab_2020-2024.md`](results/bollinger_filter_ab_2020-2024.md)) is the one run that clears 50 trades, and it shows the unfiltered signal loses money with significance: −1.88% over five years.

## What it took to get an honest number

The first backtests said +646%, then +53%, then +42.9%. Each was a measurement bug, not an edge:

- **Backtest exits were structurally unreachable** ([#84](https://github.com/gr8monk3ys/trading-bot/pull/84)). The signal generator never emitted `sell` and the engine never called `on_bar`, where all exit logic lived. Every earlier run measured enter-once-and-hold: market beta wearing the strategy's name. A second bug swallowed any exit that did fire (`await` on a synchronous broker method).
- **Position detection, naked shorts, and cash-based sizing** ([#74](https://github.com/gr8monk3ys/trading-bot/pull/74)). The strategy could not see its own positions, short sells booked no liability, and "10% of remaining cash" sizing meant a −7% drawdown was measuring idle cash, not risk control.
- **`AdaptiveStrategy` never switched** ([#89](https://github.com/gr8monk3ys/trading-bot/pull/89)). Both arms subscribed to bars themselves and traded simultaneously, sometimes against each other, while the regime detector never ran.
- **The filter carries the strategy** ([#88](https://github.com/gr8monk3ys/trading-bot/pull/88)). A/B with the Bollinger filter off was the first configuration to clear 50 trades; it is negative.

Those four defects are now checked mechanically rather than remembered. `uv run python scripts/audit_results.py` runs [backtest-audit](https://github.com/gr8monk3ys/backtest-audit) over the committed artifacts. The current exposure sweep comes back **TRUSTWORTHY WITH CAVEATS** — no blocking findings, and its two warnings are the two caveats stated above: 59% average gross exposure against a 100%-invested benchmark, and 13 round trips against a 50-trade bar. Add `--all` and the two superseded runs still come back **NOT TRUSTWORTHY**, reconstructing the position-awareness and naked-short defects from the trade log alone.

What remains on `main` is the code needed to reproduce that: the momentum and mean-reversion strategies, the adaptive coordinator, a backtest engine with slippage and spread, a risk manager (VaR, correlation, sizing), a daily-loss circuit breaker, and the Alpaca broker wrapper with a live order gateway. The exposure sweep compares strategy and benchmark at matched gross exposure so the comparison is like-for-like. Unvalidated quant work (factor models, pairs trading, a walk-forward/permutation harness) was moved off `main` to the [`archive/research`](https://github.com/gr8monk3ys/trading-bot/tree/archive/research) branch; the only piece worth revisiting is pairs trading, tracked in [#104](https://github.com/gr8monk3ys/trading-bot/issues/104).

The full history, including which numbers are superseded and why, is in [`results/where_we_landed.md`](results/where_we_landed.md).

## Run it

Needs Python 3.10+, `uv`, and the TA-Lib C library (`brew install ta-lib`; Linux recipe in [`docs/setup.md`](docs/setup.md)).

```bash
uv sync --group dev --group test
cp .env.example .env            # ALPACA_API_KEY, ALPACA_SECRET_KEY, PAPER=True (only needed for live)

uv run pytest tests/unit/
uv run python main.py backtest --strategy MomentumStrategyBacktest --symbols SPY,QQQ --start-date 2024-01-01 --end-date 2024-12-31
uv run python scripts/run_etf_baseline.py     # regenerates the table above
uv run python scripts/audit_results.py        # audits the committed artifacts
uv run python main.py live                    # paper trading
```

`docs/architecture.md` has the data flow; `docs/strategy_guide.md` describes the signals.
